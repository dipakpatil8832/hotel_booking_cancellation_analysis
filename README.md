# 🏨 Hotel Booking Cancellation Analysis using EDA

## 1 Project Overview

This project focuses on analyzing hotel booking data to understand the major factors behind booking cancellations.
Using **Exploratory Data Analysis (EDA)** techniques, the project uncovers patterns, trends, and insights that affect hotel reservation cancellations.

The analysis helps hotels improve:

* Revenue management
* Customer retention
* Booking strategies
* Cancellation prediction understanding

---

## 2  Objectives

* Analyze hotel booking behavior
* Identify major cancellation factors
* Compare cancellation trends between hotel types
* Understand customer patterns
* Perform complete Exploratory Data Analysis (EDA)

---

## 3 Dataset Information

The dataset contains hotel booking records with features such as:

* Hotel type
* Lead time
* Arrival date
* Meal type
* Market segment
* Customer type
* ADR (Average Daily Rate)
* Reservation status
* Cancellation status

Dataset includes:

* Missing values
* Categorical variables
* Numerical variables
* Real-world business data

## 4 Key Insights

* City hotels experience higher cancellation rates than resort hotels.
* Longer lead time increases cancellation probability.
* ADR significantly affects booking cancellations.
* Some room types have higher cancellation frequencies.
* Online travel agents contribute heavily to cancellations.
